# Установка Promin на Mac

Для установки не нужны аккаунт Promin или Apple Developer. Универсальный DMG поддерживает компьютеры Mac с Intel и Apple Silicon.

## Установка

1. Откройте [последний выпуск Promin](https://github.com/karolmarol931-coder/promin/releases/latest) и скачайте универсальный файл `.dmg`.
2. Откройте загруженный DMG и перетащите Promin в папку Applications.
3. Закройте окно DMG и извлеките Promin из боковой панели Finder.
4. Запустите Promin из папки Applications.
5. Если macOS заблокирует приложение, откройте **Системные настройки → Конфиденциальность и безопасность**, найдите сообщение о Promin, нажмите **Открыть всё равно** и подтвердите запуск.

macOS показывает это подтверждение, поскольку приложение распространяется без Apple Developer ID и нотариализации. Не отключайте Gatekeeper и скачивайте установщик только из [официального раздела выпусков Promin](https://github.com/karolmarol931-coder/promin/releases/latest).

## Обновления

Promin проверяет наличие обновлений при запуске и затем периодически, скачивает их в фоне и показывает уведомление, когда новая версия готова. Закройте и снова откройте приложение, чтобы начать работать с установленной версией. Для проверки и скачивания обновления нужен интернет.

Обновления проверяются отдельной подписью Tauri. Это не заменяет проверку безопасности macOS при первой установке.
